# Manifest Metals

Website for Manifest Metals, LLC: metal roofing and siding, El Paso, Texas. English and Spanish.

## How it's built
Pages are generated by `_build/build.py` (plain Python, no installs):

```
python3 _build/build.py
```

- `_build/build.py`: all page content (English and Spanish), layout and copy rules
- `_build/logo.py`: the Manifest emblem, redrawn as SVG from `manifest-logo-hires.png`
- `_build/art.py`: panel cross-section diagrams and icons
- `assets/img/p/`: real project photos (El Paso, Galveston, Houston area)
- `assets/img/r/`: color visualizer illustrations (the 12 chart colors on R-panel)

Edit content in `_build/build.py`, run the build, commit. GitHub Pages publishes `main`.

## Quote form
Posts to FormSubmit, which emails `manifestmetalsep@gmail.com`. The first submission sends a one-time activation email to that inbox; click it once and the form is live. Change `EMAIL` / `FORM_ENDPOINT` in `_build/build.py` to route leads elsewhere.
