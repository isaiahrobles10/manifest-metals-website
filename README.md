# Manifest Metals

Website for Manifest Metals, LLC: metal roofing and siding in El Paso, TX. English and Spanish.

## How it's built
The pages are generated by `_build/build.py` (plain Python, no installs needed):

```
python3 _build/build.py
```

- `_build/build.py`: all page content (English and Spanish) and layout
- `_build/art.py`: the illustrations and icons
- `assets/`: styles, script, fonts and images
- Generated pages: `index.html`, `residential/`, `commercial/`, `standing-seam-vs-r-panel/`, `about/`, `contact/`, and the same under `es/`

Edit the content in `_build/build.py`, run the build, and commit. GitHub Pages publishes `main` automatically.

## Quote form
The contact form sends through [Web3Forms](https://web3forms.com) (free). Put the access key in `WEB3FORMS_KEY` in `_build/build.py` and rebuild. Until then, the form asks visitors to call.
